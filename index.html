Welcome to JavaScript Basics!

This course will cover the fundamental concepts of JavaScript, including variables, functions, loops, arrays, and objects. By the end of this course, you'll have a solid understanding of JavaScript and be ready to build your own web applications!

Example 
if (score >= 90) {
  grade = 'A';
} else if (score >= 80) {
  grade = 'B';
} else if (score >= 70) {
  grade = 'C';
} else if (score >= 60) {
  grade = 'D';
} else {
  grade = 'F';
}

console.log(grade); // this will print the assigned grade to the console

This is a simple example of how to use if-else statements to assign grades based on scores.
